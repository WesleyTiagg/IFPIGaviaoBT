## 📱 Sobre o projeto

O IFPI Gavião é uma aplicação mobile para listar categorias, produtos e detalhes de itens do cardápio de uma lanchonete institucional. A interface foi organizada em uma estrutura baseada em MVVM simplificado, separando responsabilidades em camadas de modelo, serviço, viewmodel e view.

A aplicação simula uma consulta assíncrona ao banco de dados local com atraso de 600 ms, permitindo demonstrar comportamento realista de carregamento e exibição de dados.

## 🚀 Como executar

🚀 Como Executar o Projeto
Clone o repositório (ou o seu Fork):

1. git clone https://github.com/SEU_USUARIO/IFPIGaviaoBT.git
cd IFPIGaviaoBT

2. Instale as dependências:

npm install

3. Inicie o servidor de desenvolvimento do Expo:

npx expo start

4. Abra o aplicativo:

No celular físico usando o app Expo Go (leitura do QR Code).
No emulador Android (a) ou simulador iOS (i).
No navegador (w).
